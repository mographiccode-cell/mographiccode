# TaskFlow / مهامي

تطبيق Flutter لإدارة المهام والتذكيرات بأسلوب بسيط ونظيف قريب من تجربة تطبيقات المهام على iPhone، مع دعم كامل للعربية RTL وإملاء صوتي يعيد تشغيل جلسة التعرف تلقائياً عند انتهاء جلسة Android ما دام المستخدم لم يضغط زر الإيقاف.

## المزايا
- اليوم، المجدولة، كل المهام، المكتملة، المهمة.
- إضافة عنوان وملاحظات وتاريخ ووقت وتذكير محلي.
- بحث سريع.
- تخزين محلي على الجهاز عبر SharedPreferences.
- إملاء صوتي عربي مستمر من منظور المستخدم مع زر إيقاف يدوي.
- لا يحتاج خادم أو تسجيل دخول.

## البناء
يتم إنشاء مجلد Android تلقائياً بواسطة GitHub Actions ثم بناء APK Release باستخدام Flutter 3.47.2.
